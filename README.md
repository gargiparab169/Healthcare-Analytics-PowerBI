# Healthcare Analytics and Hospital Performance Intelligence

## Project Overview
An interactive healthcare analytics dashboard developed using Microsoft Power BI to analyze patient outcomes, treatment costs, and hospital operations.

## Dashboard Pages
- **Overview:** Summary of key healthcare performance indicators.
- **Patient Intelligence:** Patient distribution and recovery outcomes.
- **Treatment and Cost Intelligence:** Treatment patterns and healthcare expenses.
- **Hospital Operations:** Hospital departments and operational information.

## Key Features
- Interactive buttons for page navigation.
- KPI cards for important metrics.
- Matrix visuals for structured data comparisons.
- Charts and graphs for data visualization.
- Multi-page dashboard design.

## Tools Used
- Microsoft Power BI
- Data analysis and visualization
- Dashboard design and data storytelling

## Project Objective
To transform hospital data into meaningful insights through interactive visualizations and support data-driven decision-making.
